# TFU mod support

Use the issue form in the affected mod repository. English and Dutch are welcome. Keep one problem per issue and link related reports instead of opening duplicates.

## Evidence we need

- Exact mod version, ZIP filename and download source; FS25 build, map and map version.
- Singleplayer, hosted multiplayer or dedicated-server mode; affected farm/player role and relevant settings.
- Expected and actual behaviour, numbered reproduction steps, frequency and incident time.
- Complete client `log.txt` from the affected session. Dedicated-server reports also need `server.log` from that same session.
- Relevant vehicle/implement names, versions and integrations. Screenshots or a short video are useful for visual, physics, UI or interaction problems. Show the setup and failed action.
- For save/load problems: whether saving completed, what happened after restart and which backed-up save was used. Do not overwrite the only original savegame to test a problem.

The usual client log path is `Documents/My Games/FarmingSimulator2025/log.txt`. Server log locations depend on the host. Attach files rather than screenshots of long logs. If evidence is unavailable, say so; the maintainer will ask a focused follow-up.

## Privacy

Remove passwords, tokens and private connection details before publishing attachments. Public issues are public. Use a private TFU issue or an approved staff channel for private server information. Share a savegame only after checking its contents and permission.

## Follow-up

We read the supplied evidence first, then request only what is still needed for this problem. Reporter statements, hypotheses and confirmed causes are kept distinct. A report is not marked fixed merely because a patch looks plausible. Offline checks, in-game tests, dedicated-server tests and save/reload proof are recorded separately.

Public KingMods releases, private TFU builds and WIP are separate baselines. The same version number alone does not prove that two ZIPs are identical. Do not install a private server build over a public release without instructions for that server.
